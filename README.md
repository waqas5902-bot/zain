# 🎪 The Funhouse Arcade

A tiny collection of funny browser games — no dependencies, just HTML/CSS/JS.
Open **`index.html`** (or run any static server) and pick a game.

## Games

| Game | File | How to play |
|------|------|-------------|
| 🥔 Angry Potato | `potato-rage.html` | Click the potato until it hits maximum rage |
| 🏃💨 Catch the Button | `catch-the-button.html` | Catch the dodging button 6 times (wait for it to trip) |
| 🔨 Whack-a-Mole | `whack-a-mole.html` | 30 seconds — whack moles (+10) and crowns (+50), avoid bombs (−20) |
| 🤖 RPS: Sassy Bot | `rps-bot.html` | Rock-paper-scissors vs. a trash-talking bot, first to 5 |
| 🧩 2048 | `2048.html` | Merge tiles to 2048 (arrows / WASD / swipe, plus undo) |

## Run

```
python3 -m http.server 8080
# then open http://localhost:8080
```
